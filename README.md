# Muhammad Waleed Portfolio

Updated static portfolio package for `https://waleed902.github.io/portfolio/`.

## Publish on GitHub Pages

1. Open the GitHub repository that publishes the `/portfolio/` site.
2. Replace the existing site files with the contents of this folder.
3. Keep `index.html` at the repository root.
4. Commit and push the changes.
5. After GitHub Pages finishes deploying, hard-refresh the live site.

The package includes the 3D operator-laptop hero, résumé PDF, FlagSniff technical documentation, favicon, Open Graph preview image, `robots.txt`, and `sitemap.xml`.
